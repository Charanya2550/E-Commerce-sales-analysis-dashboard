# E-Commerce-sales-analysis-dashboard
An end to end data analytics project featuring python data cleaning &amp; merging, followed by an interactive Power BI dashboard tracking revenue trends and top product categories.

# Project overview
# Business Problem
The e-commerce business faced fragmented data across multiple channels and product lines, making it difficult for staleholders to evaluate revenue trends and other terms.
Data processing(python): Cleaned merged, and manipulated raw e-commerce datasets using pandas in Jupyter notebook to generate key metrics.
Data visualization(Power BI): Built an interactive dashboard featuring top-level filters, custom KPI cards, monthly revenue, and category performance breakdowns.

# Insights delivered
Category Performance: 
Furniture and outdoor drive is the highest total revenue share, highlighting primary inventory re-stocking priorities.
Channel Efficiency:
slicer controls allow marketing teams to isolate revenue generated by specific acquisition channels to optimize marketing spend. 


# Tech Stack
Python: Pandas, Matplotlib, Seaborn
Database: CSV/Excel files
BI Tool: Power BI Desktop
